## 💡 【導師講義：底層真相探究】

### 1. 事件冒泡 (Event Bubbling)

當你點擊一個按鈕時，這個點擊事件並非只停留在按鈕上。它會像水底噴出的氣泡一樣，一路向外（向上）傳遞，經過父元素、阿公元素，直到 `document`。

### 2. 事件委派的核心：一人領信

利用冒泡，我們只要在父層容器掛載一個監聽器：

- **`e.target`**：真正觸發事件的那個最底層元素（你的目標）。
- **`e.currentTarget`**：掛載監聽的那個父容器。

#### 🛠️ 實戰語法：守株待兔

```javascript
const list = document.querySelector(".button-list");

list.addEventListener("click", function (e) {
  // 透過 e.target.closest 擊中目標
  const targetBtn = e.target.closest(".btn");
  if (targetBtn) {
    console.log("點中目標按鈕了！");
  }
});
```

## ⚔️ 【戰術對抗：學長與學弟的代碼對決】

### 招式示範：一人管理整支軍隊

#### ❌ 冒險學弟：勞民傷財的個體監聽

- **負能量評級**：🔴 浪費記憶體 / 🔴 動態新增的元素會失效

```javascript
const items = document.querySelectorAll('.item');
items.forEach(i => i.addEventListener('click', () => {...}));
```

#### ✅ 勇者學長：父層大聲公委派

- **利潤評級**：🟢 效能頂尖 / 🟢 支援未來新增的元素

```javascript
document.querySelector("#parent").addEventListener("click", (e) => {
  if (e.target.nodeName === "LI") {
    console.log("子項目被點擊了");
  }
});
```

## 🏰 【勇者精英課：邁向職人的進階架構】

### 為什麼委派能處理「未來的人」？

很多冒險者發現，當他們用 `JS` 動態新增了任務卡片後，原本掛載的監聽器就失靈了。那是因為那些士兵只負責盯著「當時就在場」的人。

**委派術的奧祕：** 只要大聲公（父監聽器）還在，它管的是整個「時空區域」。不管新加入的人是誰，只要他產生的訊號傳上來，大門警衛依然能精準捕獲，這就是大型效能優化的職人技術。
