## 💡 【導師講義】

### 1. 了解我們身上的裝備 : Javascript 是什麼
*   **HTML 與 CSS**：就像是你精挑細選的長劍與華麗的斗篷，它們讓你「看起來」像個英雄，但它們是靜止的。
*   **JavaScript**：則是賦予裝備生命的**「靈魂附魔」**。
它讓你的劍能感應冒險者的揮砍（**監聽事件**）、能根據戰鬥情況變換屬性（**管理資料狀態**）。

有了 JavaScript，你就不會只是呆呆站在那裡的裝備黨，而是有強力技能的冒險者。

## ⚔️ 【實戰演武場】

### 招式示範：開啟你的「偵查之眼」！
每個冒險者都必須學會如何解讀系統訊息。在瀏覽器中，這招基礎偵查術叫做 `console.log`。

- **初階冒險者的寫法 (單純輸出訊息)：** 
  ```javascript
  console.log("Hello World");
  ```
- **領取導師 Buff 後的「系統追蹤術」：**
  ```javascript
  const heroName = "最勇敢的冒險者";
  console.log(`🛡️ [系統訊息] 歡迎來到公會，${heroName}！導師已就位。`);
  ```
> **導師講評：** 別小看這一行。
> 如果你能理解 `${heroName}` 是如何把資料塞進字串裡的，你就已經邁出了「看透資料流」的第一步。不再靠猜測（通靈），而是靠觀測。
