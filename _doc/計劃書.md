# 鐵人賽 30 天：不講廢話的 JS 視覺化指南 (計畫書)

## 🎯 核心方針
1. **去術語化**：先講畫面（視覺化/圖解），再講邏輯。
2. **React 導向**：所有選題皆為為了銜接 React 做鋪墊。
3. **高頻率互動**：每一篇都要有 CodePen 練習。

## 📅 30 天主題清單 (標題回歸版)

### 第一階段：啟航與代碼整潔術 (Day 01 - 07)
- **Day 01**：【序幕】寫程式不靠通靈！我如何幫你重塑 JS 腦袋。
- **Day 02**：別再亂貼標籤！const 與 let 的生存區域。
- **Day 03**：🏹 極速短咒：箭頭函式 => 與傳說中的隱形回傳。
- **Day 04**：【容器啟蒙】物件與陣列：裝載傳奇物資的寶箱與名單 (解構初探)。
- **Day 05**：【影印術】展開運算子 ...：一秒複製你的資料庫 (Immutability 的起手式)。
- **Day 06**：【原理】改了 A 卻壞了 B？記憶體傳址與副本的真相。
- **Day 07**：【結界】記憶膠囊（閉包）與 IIFE 結界術：守護你的區域變數。

### 第二階段：資料探勘與邏輯決策 (Day 08 - 14)
- **Day 08**：陣列大戰：從傳統 for 迴圈進化到自動化連線 map 與 filter。
- **Day 09**：物件導航：如何優雅地看透寶箱裡的秘密 (Object.keys, values)。
- **Day 10**：【圖解】this 到底是誰？變色龍盔甲的指向判定法。
- **Day 11**：類別 Class：幫你的程式碼穿上「制服」 (打造重複利用的勇者模板)。
- **Day 12**：【邏輯開關】&&、|| 與 ?? 的短路判斷：老手最愛用的簡潔語法。
- **Day 13**：DOM 樹大探險：如何從地圖中精準抓取 NPC 元素。
- **Day 14**：事件監聽：當使用者點下去後，瀏覽器發生了什麼？

### 第三階段 (Day 15 - 20)
- **Day 15**：【圖解】事件委派：一人領信，全家收件。
- **Day 16**：瀏覽器小帳本：幫使用者存下他的個人設定（LocalStorage）。
- **Day 17**：時間管理大師：Timeout 與 Interval 的實作應用。
- **Day 18**：【期中實戰】純 JS 打造你的第一個「待辦清單」。
- **Day 19**：【圖解】為什麼程式不乖乖排隊？JS 腦袋裡的 Event Loop。
- **Day 20**：Promise：給未來的一個承諾，解決你的回呼地獄。

### 第四階段：與外部世界的連結 (Day 21 - 25)
- **Day 21**：Async / Await：用人類的語言，處理還沒回來的資料。
- **Day 22**：Fetch API 實戰：向遙遠的王國請求後勤物資 (API 串接)。
- **Day 23**：錯誤處理：使用 Try...Catch 穿上你的復活保險甲。
- **Day 24**：程式碼分家：Module 系統 (import/export) 讓你的小隊分工。
- **Day 25**：【效能神兵】防抖 (Debounce) 與節流 (Throttle) 的冷卻機制。
