## :date: 30 天進度藍圖

### 第一階段：啟航與代碼整潔術（Day 01 - 07）
**重點：** 改掉舊習慣，學會新時代的標籤與工具。

- **Day 01**：【序幕】寫程式不靠通靈！我如何幫你重塑 JS 腦袋（計畫介紹）。
- **Day 02**：別再亂貼標籤！const 與 let 的生存區域。
- **Day 03**：快閃函式 =>：讓你少寫好幾行字，代碼變漂亮。
- **Day 04**：文字拼接術：告別 + 號按到眼花的惡夢。
- **Day 05**：【開箱術】物件解構：不用點 (.) 也能精準拿資料。
- **Day 06**：陣列排排站：為什麼資料的「順序」與「開箱」這麼重要？
- **Day 07**：神奇噴漆 ...：一秒複製你的資料庫，不再怕弄壞原始資料。

---

### 第二階段：邏輯進化與核心機制（Day 08 - 14）
**重點：** 透過圖解，搞定那些讓你頭髮掉光的 JS 魔王。

- **Day 08**：【圖解】改了 A 卻壞了 B？這不是靈異現象，是記憶體位置。
- **Day 09**：【圖解】記憶膠囊（閉包）：讓你的變數擁有「長久記憶」的超能力。
- **Day 10**：資料變身術：別再用 for 迴圈了，讓 Map 幫你轉換資料。
- **Day 11**：精準過濾術：Filter 幫你從亂碼中秒找資料。
- **Day 12**：【圖解】this 到底是誰？一場關於「呼叫者」的找尋之旅。
- **Day 13**：類別 Class 只是外殼：JS 其實是「原型」在搞鬼。
- **Day 14**：邏輯小幫手：&&、|| 與 ?? 的短路判斷，少寫一半的 if...else。

---

### 第三階段：瀏覽器互動與實戰（Day 15 - 20）
**重點：** 看得見的網頁互動，體會「手動操作」的樂趣與辛苦。

- **Day 15**：DOM 樹大探險：如何精準抓取網頁裡的元素？
- **Day 16**：事件監聽：當使用者點下去後，瀏覽器發生了什麼？
- **Day 17**：【圖解】事件委派：一人領信，全家收件（效能優化）。
- **Day 18**：瀏覽器小帳本：幫使用者存下他的個人設定（LocalStorage）。
- **Day 19**：時間管理大師：Timeout 與 Interval 的實作應用。
- **Day 20**：【期中實戰】純 JS 打造你的第一個「待辦清單」。

---

### 第四階段：非同步探險與模組化（Day 21 - 25）
**重點：** 處理那些「需要等一下」的事情，讓程式井然有序。

- **Day 21**：【圖解】為什麼程式不乖乖排隊？JS 腦袋裡的 Event Loop。
- **Day 22**：Promise：給未來的一個承諾，解決你的回呼地獄。
- **Day 23**：Async / Await：用最直覺的寫法處理「還沒回來的資料」。
- **Day 24**：Fetch API 實戰：如何優雅地從外部搬運資料。
- **Day 25**：錯誤處理：使用 Try...Catch 讓你的網頁不會整頁白屏。

---

### 第五階段：高階技巧與大揭秘（Day 26 - 30）
**重點：** 揭曉隱藏了 28 天的終極真相。

- **Day 26**：程式碼分家：用 import 與 export 讓專案像樂高一樣組合。
- **Day 27**：效能神兵：防抖 (Debounce) 與節流 (Throttle)。
- **Day 28**：常用 ES+ 語法補完：可選鏈結與空值合併的防錯術。
- **Day 29**：【驚喜揭曉】原來這 30 天，你已經練就了 React 的核心靈魂！
- **Day 30**：【完賽感言】這不只是結束，是你通往現代前端的大門。
