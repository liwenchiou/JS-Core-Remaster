# 鐵人賽 30 天：不講廢話的 JS 視覺化指南 (計畫書)

## 🎯 核心方針
1. **去術語化**：先講畫面（視覺化/圖解），再講邏輯。
2. **React 導向**：所有選題皆為為了銜接 React 做鋪墊。
3. **高頻率互動**：每一篇都要有 CodePen 練習。

---

## 📅 30 天主題清單 (標題回歸版)

### 第一階段：啟航與代碼整潔術 (Day 01 - 07)
- **Day 01**：【序幕】寫程式不靠通靈！我如何幫你重塑 JS 腦袋 (計畫介紹)。
- **Day 02**：別再亂貼標籤！const 與 let 的生存區域。
- **Day 03**：快閃函式 =>：讓你少寫好幾行字，代碼變漂亮。
- **Day 04**：【開箱術】物件解構：不用點 (.) 也能精準拿資料。
- **Day 05**：神奇噴漆 ...：一秒複製你的資料庫，不再怕弄壞原始資料。
- **Day 06**：【圖解】改了 A 卻壞了 B？這不是靈異現象，是記憶體位置。
- **Day 07**：【圖解】記憶膠囊（閉包）：讓你的變數擁有「長久記憶」的超能力。

### 第二階段 (Day 08 - 14)
- **Day 08**：陣列大戰：從傳統 for 迴圈到現代的 map 與 filter。
- **Day 09**：物件導航：如何優雅地遍歷與操作你的寶箱。
- **Day 10**：【圖解】this 到底是誰？一場關於「呼叫者」的找尋之旅。
- **Day 11**：類別 Class 只是外殼：JS 其實是「原型」在搞鬼。
- **Day 12**：邏輯小幫手：&&、|| 與 ?? 的短路判斷。
- **Day 13**：DOM 樹大探險：如何精準抓取網頁裡的元素？
- **Day 14**：事件監聽：當使用者點下去後，瀏覽器發生了什麼？

### 第三階段 (Day 15 - 20)
- **Day 15**：【圖解】事件委派：一人領信，全家收件。
- **Day 16**：瀏覽器小帳本：幫使用者存下他的個人設定（LocalStorage）。
- **Day 17**：時間管理大師：Timeout 與 Interval 的實作應用。
- **Day 18**：【期中實戰】純 JS 打造你的第一個「待辦清單」。
- **Day 19**：【圖解】為什麼程式不乖乖排隊？JS 腦袋裡的 Event Loop。
- **Day 20**：Promise：給未來的一個承諾，解決你的回呼地獄。

### 第四階段 (Day 21 - 25)
- **Day 21**：Async / Await：用最直覺的寫法處理「還沒回來的資料」。
- **Day 22**：Fetch API 實戰：如何優雅地從外部搬運用資。
- **Day 23**：錯誤處理：使用 Try...Catch 讓你的網頁不會整頁白屏。
- **Day 24**：程式碼分家：用 import 與 export 讓專案模組化。
- **Day 25**：效能神兵：防抖 (Debounce) 與節流 (Throttle)。

### 第五階段 (Day 26 - 30)
- **Day 26**：常用 ES+ 語法補完：可選鏈結與空值合併。
- **Day 27**：從「手動操作」到「戰略指揮」：JS 高階架構思維。
- **Day 28**：【驚喜揭曉】原來這一路走來，你已經練就了 React 的核心靈魂！
- **Day 29**：【實戰】重鑄你的傳奇裝備：將「任務佈告欄」升級為 React 版
- **Day 30**：【結語】冒險還沒結束！你的 JS 重塑之旅才正要開始。
