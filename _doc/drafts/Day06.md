## 💡 【導師講義：圖解底層真相】

### 1. 為什麼要影印？（傳單 vs. 鑰匙）
在學魔法（展開運算子）前，我們要先搞清楚為什麼「直接賦值（`=`）」在 JS 世界裡是有風險的：

*   **影印傳單 (Pass by Value)**：
    想像你有一張寫著 `const price = 100` 的傳單。當你把這個值給別人時，JS 是直接「影印」一份給他。他在他的紙上改數字，完全不會影響你的內容。 (適用於：數字、字串)
*   **共用鑰匙 (Pass by Reference)**：
    但當我們處理「陣列」或「物件」時，情況就變了。`const team = ["勇者"]` 就像是一間儲藏室。當你把 `team` 給別人時，你不是送他一間房間，而是送他 **「同一把鑰匙」**。他進去改了裡面的隊員，你打開門看到的也是改過的結果！

> **導師的圖解心法：** 
> 基礎型別是「直接送貨」，拿了就走；引用型別是「送鑰匙」，大家都對同一個空間負責。

### 2. 展開魔法：打破容器，重新裝填
展開運算子 `...` 的動作非常直覺：它會將原本裝在「陣列」或「物件」裡的物資全部「倒出來」，然後讓你放進一個**全新**的容器裡。

```javascript
const oldScroll = ["火球術", "治癒術"];

// ✅ 影印術：用三個點把它「倒進」新陣列
const newScroll = [...oldScroll]; 

newScroll.push("傳送術");

console.log(oldScroll); // ["火球術", "治癒術"] (原版毫髮無傷！)
console.log(newScroll); // ["火球術", "治癒術", "傳送術"]
```

> **導師的圖解心法：** 
> 想像 `oldScroll` 是個舊木箱。`...` 的動作就是把箱子拍碎，讓裡面的捲軸飄在空中。接著，我們用 `[]`（等號右邊的新括號）變出一個全新的鋼鐵箱，把那些捲軸接住。
> 因為箱子是新的，你往裡面塞炸彈，舊箱子也不會爆炸。

## 🛖 【營火叮嚀：導師的經驗談】
> 導師以前剛出道的時後，很喜歡寫 `const newTeam = oldTeam;`。
> 我以為這樣就複製好了，結果這只是「在同一份合約上多貼一個標籤」。你在 `newTeam` 裡面加人，`oldTeam` 也會變動。
> 
> 這種現象叫「副作用（Side Effects）」。在未來你接觸那套「神奇重鑄架構」時，這招簡直是呼吸般的必備技能。記住：**永遠不要直接改動原來的物資（State），先影印一份，再改副本。**

## ⚔️ 【演武場：從冒險者到勇者辛梅爾】

### 招式示範：物件的合併與擴充
如果 NPC 給了你一份個資，你想保留原資料，但加上一把武器，該怎麼做？

#### ❌ 冒險者：危險的「直接改原版」
```javascript
const user = { name: "欣梅爾" };
const editUser = user; // 這不是複製！這是分身！

editUser.weapon = "聖劍"; // 慘了，user 裡面也有聖劍了
```

#### ✅ 勇者辛梅爾：優雅的「解構合併」
```javascript
const user = { name: "欣梅爾" };

// ✅ 打開舊包裹 (user)，加上新裝備，裝進新包裹
const upgradedUser = { 
    ...user, 
    weapon: "傳奇聖劍", 
    level: 99 
};
```

> **導師講評：** 你看，勇者的寫法不僅乾淨，還能在合併的瞬間「進化」屬性。如果 `...user` 裡面原本就有 `level`，後面的 `level: 99` 就會覆蓋掉前面的值。這種「後蓋前」的邏輯，在更新複雜物資時超級好用！

---

#### ⚠️ 【實戰雷區：避開那些致命陷阱】
> **小心「淺層影子」！**
> 展開運算子只能幫你影印「第一層」的物資。如果你的物件裡面還藏著另一個小物件（巢狀結構），裡面的小物件依然是連在一起的。
> 當你要複製一個「很多層」的巨型資料庫時，這招雖然快，但要注意它並非「深度影印術」。這個陷阱我們在 Day 06 的記憶體迷宮會詳細拆解。

## 🏰 【勇者精英課：邁向職人的進階架構】

### 其餘參數 (Rest Parameters)：剩下的都進麻袋！
除了展開，`...` 還有另一個身份叫 **「其餘參數」**。這招出現在「函式接收處」：

```javascript
function guildReward(firstGold, ...others) {
    console.log(`首獎：${firstGold}`);
    console.log(`後勤補給：`, others); // others 會變成一個陣列
}

guildReward("1000G", "水", "糧草", "地圖");
```

這在現代開發中徹底取代了舊時代的 `arguments` 物件。它讓你的函式能像「無限大的口袋」一樣，接收數不清的戰利品。

## 📝 【夥伴筆記：今日修煉精華】
##### *這份筆記是你的隨身護身符，卡關時看一眼，真相就在裡面。*
- **展開運算子 (...)**：放在物件或陣列內，用於打破容器提取資料。
- **純淨複製 (New Reference)**：建立新容器（`[]` 或 `{}`）配上展開符，避免改到原資料。
- **合併術**：後面的屬性會覆蓋前面的屬性，方便快速更新局部資料。
