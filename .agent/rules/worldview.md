# 🛡️ 《JS 核心重構：勇者轉職傳說》世界觀設定

## 1. 核心世界觀：傳奇冒險者公會：新手培育計畫 (The Remaster Guild)
*   **背景**：
    你是一名剛踏入「Web 開發」大陸的新手。為了不被外面的 Bug 潮淹沒，你來到了傳說中的公會，繳交了 30 天的訓練費用，準備接受導師最紮實的基層訓練，目標是拿起傳說中的神兵利器 **「React 聖劍」**。
*   **公會角色**：
    *   **導師**：公會裡慈祥且資深的傳奇工程師，負責揭開 JS 的底層真相，並在營火旁分享避坑經驗。
    *   **讀者 (新夥伴)**：簽下 30 天成長契約，渴望脫胎換骨、成功轉職的見習勇者。
*   **終極目標**：
    在第 30 天，讓新夥伴能親手「重鑄」他們的任務佈告欄，正式成為具備 React 戰力的專業開發者。

## 2. 訓練進行方式：30 天的成長循環
每一天，新夥伴來到公會訓練場都會經歷以下流程：
1.  **確立契約 (Rule)**：閱讀 **「修煉規則」**，確立當天的實作機制與心理準備。
2.  **領取委託 (Scenario)**：接到導師發布的 **「公會委託」**，進入沉浸式的情境故事。
3.  **洞察真相 (Truth)**：透過 **「導師講義」** 圖解看透代碼底層邏輯。
4.  **營火交心 (Wisdom)**：聆聽導師在 **「營火叮嚀」** 中分享的實務痛點。
5.  **姿勢校正 (Practice)**：在 **「演武場」** 比較「菜鳥寫法」與「專家姿勢」，並識別 **「實戰雷區」**。
6.  **邁向職人 (Elite)**：透過 **「勇者精英課」** 深化架構思維，埋下不具名的伏筆。
7.  **交付成果 (Deliver)**：在 **「公會佈告欄」** 繳交 CodePen 實作與鑑定報告。

## 3. 公會運行的三大守則 (SoP)
1.  **禁提 Boss 的真名**：在第 28 天之前，絕對不直接提到「React」或「Hooks」等名詞。保持最強烈的懸念。
2.  **視覺最優先**：每一篇任務都**必須**搭配一張圖解圖。如果沒有圖，讀者就看不見真相（原理）。
3.  **不講廢話，只講實踐**：不鑽研過時的 JS 歷史概念，每一章都要回歸到「這招在現代開發中怎麼用才穩健」。
