# 🛡️ 鐵人賽文章品質檢查手冊

此 Skill 用於確保每一篇產出的文章都符合「傳奇冒險者公會」的高品質標準。

## 🔍 檢查項目

### 1. 結構與格式 (Structure & Format)
- [ ] **部落格連結**：確認文章開頭是否包含 `本文同步分享於個人部落格` 且連結到正確的個人部落格位址。
- [ ] **模板符合度**：確認文章結構與順序是否 100% 符合 `_doc/article_template.md` 的規範。
- [ ] **結構完整性**：確認是否包含「公會任務、課前叮嚀、視覺化拆解、代碼演武、精英課、修煉精華、本日任務、進階卷軸」這八大功能區塊。

### 2. 世界觀與語氣 (Tone & Mood)
- [ ] **身分代入**：作者是否以「公會導師」的身分說話？讀者是否被稱為「勇者」或「冒險者」？
- [ ] **排解焦慮**：語氣是否鼓勵？是否避免了生硬的教學感？
- [ ] **禁忌檢查**：除了「精英課」區塊外，**絕對嚴禁**提到「React」、「Hooks」、「useState」、「Vue」等具體框架名稱。

### 3. 技術與連結規格 (Technical Specifications)
- [ ] **圖片連結檢測**：確認所有圖片是否皆已由 **外部圖床** 託管並提供有效連結。應避免使用本地相對路徑，以確保部落格發布後的穩定性。
- [ ] **CodePen 連結**：確認「公會佈告欄」區塊是否已置入有效的 CodePen 連結。
- [ ] **代碼質量**：是否優先展示現代 ES6+ 寫法？
- [ ] **連結正確性**：確認所有外部連結（如 MDN）是否正確有效。

## 🛠️ 執行流程
1. 讀取目標文章 `.md` 檔案。
2. 對照上述清單進行逐項掃描。
3. **產生「導師品質鑑定報告」**，報告必須包含以下固定區塊：
   - 🏆 **鑑定總評**：給予文章一個等級（如：傳奇、優秀、待修煉）。
   - ❌ **【不符合規範清單】**：若有任何檢查項未通過，**必須在此區塊詳細列表說明**。若全部通過則標註「無」。
   - ✅ **優點點評**：標註文章中亮點。
   - ⚠️ **具體修正建議**：根據不符合清單提供改進方向。
   - 🔮 **伏筆校對**：確認是否正確處理了隱形伏筆。
4. 若有嚴重偏離世界觀的地方，必須進行適度的「語氣修復」。
