# 🏹 CodePen 演武場題目生成 Skill

此 Skill 用於根據當日的「導師講義」自動產出難度適中、且具備公會冒險感的 CodePen 練習題目。

## 🎯 目標與原則

1.  **難度適中**：題目應涵蓋基礎觀念應用到微進階的組合，確保冒險者能從實作中獲得成就感。
2.  **RPG 世界觀**：題目內容應鎖定在公會、戰鬥、物資管理、魔法吟唱等情境。
3.  **在地化術語**：嚴格使用台灣正體技術用語（程式、資料、元件、記憶體）。
4.  **格式統一**：遵循 `_doc/codepen/style.css` 提供的視覺暗示，代碼結構必須清晰且易於閱讀。

## 🔍 生成規範

### 1. 檔案命名與存放
- **檔名**：`DXX.js` (例如：`D04.js`)。
- **路徑**：`_doc/codepen/`。

### 2. 檔案結構 (Template)
每一份 JS 檔案必須包含以下區塊：
- **頂部標題**：`// ⚔️ Day XX：[標題] ⚔️`
- **任務說明**：告知讀者如何打開 Console 並操作。
- **練習區塊**：每個練習包含：
    - `// ==========================================` 分隔線。
    - `// 練習X：[冒險主題名稱]`。
    - `/* 題目區 ... */`：描述情境與任務需求。
    - `/* ✍️ 作答區 */`：**零解答鎖定 (Zero-Answer Lock)**。不得提供任何具體邏輯實作。僅限起始代碼、空函式或情境引導註解。嚴禁包含 `預期輸出 90` 等解答暗示。
- **底部總結**：鼓勵文字與回傳指引。

### 3. 題目設計維度
- **語法基礎**：基本 API 或語法結構的練習（如：解構、宣告）。
- **邏輯組合**：結合先前的知識點進行複合運算。
- **陷阱辨識**：故意提供錯誤代碼讓讀者修復，印證「學長與學弟」的差異。
- **故事鎖定**：題目練習必須圍繞「辛梅爾 (Himmel)」一行人的探險數據進行設計。
- **[NEW] 鑑定題引導**：在 JS 檔案末尾，應附註當天「感性成就感」與「理性觀念辨析」的問題提示，方便冒險者回填戰報。

## 🛠️ 執行指令語法
當使用者輸入 `/codepen DayXX` 時：
1. 讀取 `Posts/XX-Folder/DayXX.md`。
2. 提取當天的關鍵知識點。
3. 根據上述規範生成內容。
4. 將生成內容寫入 `_doc/codepen/DXX.js`。
