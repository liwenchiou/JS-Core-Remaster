# ⚔️ JS 核心重構：勇者轉職傳說 (JS-Core-Remaster)

> **「不講廢話，去術語化。帶你用 30 天，重塑 JS 腦袋，迎接 React 傳奇。」**

## 📖 專案簡介
這是一個結合 **RPG 冒險世界觀** 與 **視覺化原理拆解** 的 JavaScript 學習專案。主要目標是協助具備基礎經驗或 MIS 背景的開發者，透過 30 天的「重塑（Remaster）」工作流，徹底掌握 JS 底層邏輯，並無縫銜接至現代 React 開發架構。

## 🏗️ 專案架構
- **`.agent/`**：公會核心規章（身分、配色、寫作模板、AI 協作指令）。
- **`_doc/`**：公會檔案室（計畫書、草稿沙盒 `drafts/`、執行狀態 `state/`、CodePen 演武場）。
- **`Posts/`**：完成修煉的文章正文。

## 🤖 AI 協作模式
本專案由導師與一組 AI 協作團隊共同維護，支援以下提及語法：
- `@Architect`：內容架構與邏輯佈局。
- `@Reviewer`：技術審核與術語校正。
- `@NewbieTester`：新手易讀性壓力測試。
- `@VeteranTester`：技術深度與 React 伏筆探查。

## 🛠️ 開發流程 (The Remaster Pipeline)
1. **草稿撰寫**：於 `_doc/drafts/` 生成文章。
2. **品質鑑定**：經由測試員與審稿人會審。
3. **正式發布**：移動至 `Posts/` 目錄。
